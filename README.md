# LifeLedger – Frontend

LifeLedger is a web application that helps users manage important records, warranties, renewals, reminders, and other life-admin activities.

## Live Demo
- **Website:** https://life-ledger-frontend.vercel.app
- **Backend API:** https://lifeledger-backend-claz.onrender.com

## Tech Stack
- React
- Vite
- JavaScript
- Axios
- CSS

## Features
- User registration and login
- Dashboard
- Record management
- Reminders and history
- Backend API integration
- Persistent data storage through the backend

## Installation and Setup

**1. Clone the repository**
```bash
git clone https://github.com/ashrith-17/LifeLedger-Frontend.git
cd LifeLedger-Frontend
```

**2. Install dependencies**
```bash
npm install
```

**3. Configure the API URL**

Create a `.env` file in the project root:

```env
VITE_API_URL=https://lifeledger-backend-claz.onrender.com
```

**4. Start the development server**
```bash
npm run dev
```

**5. Build for production**
```bash
npm run build
```

## Deployment
The frontend is deployed using Vercel.
